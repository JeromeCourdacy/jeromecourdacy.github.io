UNO Game State Recognition

For an image analysis course, our team built a vision pipeline that reconstructs the state of an UNO game from a single image, across varied backgrounds. It identifies the cards held by each player, the cards in the center, and the current player.

We combined classical computer vision techniques with a neural network we built and trained to classify UNO card symbols, using Python and PyTorch. Our solution achieved 98% accuracy on the test dataset, up from a baseline of 63%.

Python PyTorch Computer vision Neural networks

Autonomous Mobile Robotics

Our team built a Thymio robot navigation system that reached a target while avoiding mapped obstacles and reacting to unexpected obstacles using proximity sensors.

The system combined overhead camera tracking with ArUco markers, A* path planning, and an Extended Kalman Filter to fuse vision and wheel odometry.

My contributions: computer vision and local obstacle avoidance, including camera calibration, obstacle detection, and reactive navigation.

Python OpenCV Thymio ArUco A* Sensor fusion

Copycat Portfolios

Can copying politicians’ stock trades outperform the market? For EPFL’s Applied Data Analysis course, our team combined US congressional trading disclosures with historical stock prices to study politicians’ portfolios and simulate strategies that copy their trades after disclosure.

We explored how disclosure delays and the selection of politicians affect performance, comparing returns and risk-adjusted metrics against an S&P 500 benchmark. The project brings together data preparation, portfolio simulation, statistical analysis, and a dedicated data story website. We identified a market-outperforming strategy based on public disclosures of US politicians’ trades in our analysis.

My contributions: led the copycat strategy analysis, contributed to data cleaning and preprocessing, and wrote the website introduction while maintaining a consistent writing style across the story.

Python Data analysis Portfolio simulation Data visualization

Vision-Based Autonomous Drone Racing

Our team developed the vision and control components for a Crazyflie quadcopter, with the goal of flying through a series of gates as quickly as possible. We first built the system in Webots simulation, then implemented it on the real quadcopter in the lab, taking the project from a simulated environment to physical hardware. The pipeline combined gate detection, navigation, and closed-loop control, with real-time gate finding and autonomous navigation on the physical platform.
